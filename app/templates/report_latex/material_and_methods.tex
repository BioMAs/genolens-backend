
\subsection{Input Data}
The analysis was performed on the provided gene-level count matrix. Samples below the minimum sequencing depth or number of detected genes set for the analysis were excluded. Genes with very low expression were then removed: a gene was kept when it reached the minimum count set for the analysis (10 by default) in at least as many samples as the smallest compared condition contains, the rule of edgeR's \textit{filterByExpr} (Chen et al., 2016); above ten samples per condition the requirement is relaxed to $10 + 0.7\,(n - 10)$ samples. A gene expressed in a single condition is therefore retained, whereas a gene detected in fewer samples than any condition holds is not. When a fixed number of samples was set for the analysis instead, that number applies.

\subsection{Differential Gene Expression Analysis}

Differentially expressed genes (DEGs) were called with \textbf{DESeq2} (Love et al., 2014), which fits a negative binomial generalised linear model with shrinkage of the dispersion estimates and tests each gene with a Wald test. P-values were corrected for multiple testing using the Benjamini-Hochberg (BH) False Discovery Rate. A gene was classified as a DEG if (i) its DESeq2 adjusted p-value was below the FDR threshold set for the analysis (0.05 by default), and (ii) its absolute DESeq2 log$_2$ fold-change (maximum-likelihood estimate, unshrunken) was at or above the fold-change threshold set for the analysis (log$_2$(1.5) by default).

To show how robust each call is, two complementary frameworks were applied to the same counts and reported alongside DESeq2, without changing the DEG list:

\begin{enumerate}
  \item \textbf{edgeR} (Robinson et al., 2010): fits a negative binomial model on TMM-normalised counts and performs quasi-likelihood F-tests to account for overdispersion.
  \item \textbf{limma-voom} (Ritchie et al., 2015): models log-transformed data with precision weights derived from the mean--variance trend and employs empirical Bayes shrinkage of variance estimates.
\end{enumerate}

For each gene, the number of methods in which it is significant is reported. A combined p-value (Stouffer's Z-score method) is also provided for information only: it assumes independent tests, whereas the three methods analyse the same counts and give strongly correlated p-values, so the combination overstates significance and is not used to call DEGs.

\subsection{Functional Enrichment Analysis}

Functional enrichment analysis was performed using an over-representation analysis (ORA) approach against the local annotation database. Analyses were conducted separately for up-regulated and down-regulated DEG sets.

\textbf{Over-representation analysis (ORA)} tested whether DEGs were significantly over-represented in curated biological term sets using hypergeometric tests against multiple databases: Gene Ontology (GO --- Biological Process, Molecular Function, Cellular Component), KEGG pathways, Reactome pathways, WikiPathways, and MSigDB gene set collections (Hallmark, C2, C5, C6, C7).

Only results with Benjamini-Hochberg adjusted p-value $\leq$ 0.05 are reported. In dotplots, dot size reflects the gene ratio (proportion of DEGs annotated to that term) and dot colour represents statistical significance ($-\log_{10}$ adjusted p-value).
